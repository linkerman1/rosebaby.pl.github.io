# RoseBabySecondhand

Statyczna strona RoseBabySecondhand. HTML, CSS, JavaScript i zdjęcia.

## Pliki
- `index.html` — treść strony
- `style.css` — wygląd i wersja mobilna
- `script.js` — menu oraz powiększanie zdjęć
- `assets/` — wszystkie zdjęcia

## Uruchomienie lokalne

W katalogu repozytorium uruchom `python3 -m http.server 8000`, a następnie otwórz http://localhost:8000.

## Publikacja

Działająca strona: https://rosebaby-secondhand.oleksiy0007.chatgpt.site

Repozytorium jest kopią kodu opublikowanej strony. Zmiany na GitHubie nie są automatycznie synchronizowane z hostingiem Sites. Pliki w katalogu głównym nadają się również do hostingu statycznego.

## Wersja mobilna

Zdjęcia zachowują naturalne proporcje. Główna galeria ma jedną kolumnę na telefonach, a galeria Instagram — dwie kolumny z pełnymi kadrami. Arkusz stylów ma wersjonowany adres, aby przeglądarka pobierała aktualizacje.
